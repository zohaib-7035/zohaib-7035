## About

Hi, I'm **Zohaib**, a Data Science student at **FAST NUCES** in Lahore. I build machine learning solutions that simplify and supercharge daily life, and I turn raw data into insights you can actually act on.

<details>
<summary><b>What I build</b></summary>

- **Applied AI** for real problems: crop advice for farmers, plant disease detection, early Alzheimer's screening, and stock analysis

<details>
<summary><b>🌾 AgroBot: Smart Crop Advisory System</b></summary>

A desktop advisory system that helps farmers pick crops and plan irrigation and fertilization using soil type, weather, and crop history.

**Team project.** My role: requirements engineer, architect, and frontend developer.

![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=csharp&logoColor=white) ![SQLite](https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white)

🔗 [View repository](https://github.com/zohaib-7035/AgroBot-Agricultural-Prediction-and-Recommendation-System)

</details>

<details>
<summary><b>🌿 Plant Disease Classifier</b></summary>

A Streamlit web app. Upload a leaf photo and get the predicted condition, a confidence score, and a class probability chart. The CNN was trained on the PlantVillage dataset and covers 38 plant conditions.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white) ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white) ![Jupyter](https://img.shields.io/badge/Jupyter-F37626?style=flat-square&logo=jupyter&logoColor=white)

🔗 [View repository](https://github.com/zohaib-7035/Plant-Disease-Classifier-Using-Image-Data-BY-CNN)

</details>

<details>
<summary><b>🧠 Alvira: Alzheimer's Early Detection Platform</b> <i>(fork)</i></summary>

A multi-modal platform for early Alzheimer's screening. It analyzes speech patterns (WaveNet), medical images (OpenCV), and symptoms (SVM), behind a React and Vite interface.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white) ![PyTorch](https://img.shields.io/badge/PyTorch-EE4C2C?style=flat-square&logo=pytorch&logoColor=white) ![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB) ![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white) ![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white)

🔗 [View repository](https://github.com/zohaib-7035/Alvira-Alzheimer-Early-Detection)

</details>

<details>
<summary><b>💹 FinDocMadeEz: AI Financial Document Analyst</b> <i>(fork)</i></summary>

Ask questions about financial filings and get sourced answers through RAG. It also includes sentiment analysis, LSTM-based volume forecasting, and an investment decision engine, all in a Streamlit dashboard. Built for the AkashX.ai challenge.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white) ![Plotly](https://img.shields.io/badge/Plotly-3F4F75?style=flat-square&logo=plotly&logoColor=white)

🔗 [View repository](https://github.com/zohaib-7035/FinDocMadeEz)

</details>

<details>
<summary><b>🎯 SkillSense: AI Career Development Platform</b></summary>

Pulls skills from resumes and GitHub, shows them on an interactive 3D skill map, unlocks skills through quests, and runs gap analysis against target roles. Built on Lovable with Supabase and Gemini 2.5 Flash.

![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB) ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white) ![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white) ![Tailwind](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=flat-square&logo=tailwindcss&logoColor=white) ![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white)

🔗 [View repository](https://github.com/zohaib-7035/Skill-Sense)

</details>

<details>
<summary><b>📈 AI Stock Intelligence Platform</b></summary>

A free, fully local stock analysis tool. A multi-agent pipeline combines sentiment, technical signals, risk, and macro data. It also has a portfolio optimizer, backtester, and scenario simulator, all running on a local Ollama model. It has 532+ tests across 21 backend modules.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white) ![SciPy](https://img.shields.io/badge/SciPy-8CAAE6?style=flat-square&logo=scipy&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black) ![Ollama](https://img.shields.io/badge/Ollama-111111?style=flat-square)
